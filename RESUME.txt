Feature	Redis Command	Description
Create / Add members	ZADD	Adds one or more members with a score. Updates score if member exists.
Retrieve member rank	ZRANK	Returns the index (0-based) of the member, ordered by score.
List members	ZRANGE	Returns a range of members by index (e.g., ZRANGE key 0 5).
Count members	ZCARD	Returns the total number of elements in the set.
Retrieve score	ZSCORE	Returns the score associated with a specific member.
Remove a member	ZREM	Removes the specified member from the set.
